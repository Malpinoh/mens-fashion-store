# Men's Fashion Store

A mobile-first men's fashion storefront built with React, TypeScript and Vite.

## Features
- Men's shirts
- Trousers
- Football/soccer jerseys
- Product search
- Category filtering
- Responsive product grid
- Cart selection
- WhatsApp order handoff
- SEO-ready metadata
- Premium editorial fashion layout

## Development

```bash
npm install
npm run dev
```
